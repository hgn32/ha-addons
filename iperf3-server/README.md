# iperf3 Server

[iperf3](https://github.com/esnet/iperf) のサーバー（`iperf3 -s`）を Home Assistant 本体で動かすアドオンです。
LAN 内の PC やスマートフォンと HA 本体の間の通信速度を測れます。

## 使い方

1. アドオンを起動する（既定ではポート `5201` で待ち受けます）
2. 測りたい端末で iperf3 のクライアントを実行する

```sh
iperf3 -c <HA の IP アドレス>          # 端末 → HA（アップロード方向）
iperf3 -c <HA の IP アドレス> -R       # HA → 端末（ダウンロード方向）
iperf3 -c <HA の IP アドレス> -u -b 0  # UDP
```

測定結果はアドオンの **ログ** タブにも出ます。

## 設定

| 項目 | 既定値 | 内容 |
|---|---|---|
| `port` | `5201` | 待ち受けるポート（TCP と UDP） |

## 注意

- HA 本体のネットワークをそのまま使います（`host_network`）。ネットワークの仮想化を挟まずに測るためです
- iperf3 のサーバーは同時に1つの測定しか受け付けません。測定中に別の端末から始めると「busy」で断られます
- 認証はありません。ルーターでこのポートをインターネットへ公開しないでください
- iperf3 は公式のソース（[downloads.es.net](https://downloads.es.net/pub/iperf/)）からビルドしています。
  Alpine のパッケージは 3.20 で、3.22 で直ったサーバー側の脆弱性が残っているためです
