# Quake Panel

常時表示型の地震速報パネル [hgn32/quake-panel](https://github.com/hgn32/quake-panel)
を Home Assistant アドオンとして動かします。

強震モニタ（防災科学技術研究所）のリアルタイム震度マップを常に表示し、
緊急地震速報・地震情報・津波予報を受けたら**音と画面明滅**で気づかせます。
データ源は強震モニタと P2P地震情報で、どちらも無償です。

- 平常時: 日本全体のリアルタイム震度マップ ＋ 地震情報の履歴
- 緊急地震速報の受信時: 予想最大震度の大型表示と赤い明滅
- 外部（強震モニタ / P2P地震情報）と通信するのはこのアドオンだけで、
  画面を開いた端末は外部と直接通信しません

## 使う前に必ず読むこと（利用条件）

強震モニタのコンテンツは**複製・転載・改変・送信・再配布が禁止**されています。
このアドオンはサーバーが取得した画像を画面へ中継するため、**利用範囲を
私的使用に収めることが成立条件**です。

1. **不特定多数がアクセスできる状態にしない。** Ingress（サイドバーの
   「地震速報」）は Home Assistant のログインで保護されます。直接アクセス用の
   ポート 8080 は LAN 内に留め、**インターネットへ素で公開しないでください**。
2. **クレジット表示を消さない。** 画面左下に常時表示しています。
3. **サービス化・配信への転用をしない。** 第三者への配信、通知サービス、
   SNS への自動投稿などに使わないでください。

詳しい背景と、実装上引いてある線（震度値を画像から復元しない、独自の到達予測を
計算しない、など）は上流の
[README](https://github.com/hgn32/quake-panel#readme) にあります。

## インストール

1. Home Assistant の **設定 → アドオン → アドオンストア** を開く
2. 右上のメニューから **リポジトリを追加** を選択し、以下の URL を入力する
   ```
   https://github.com/hgn32/ha-addons
   ```
3. **Quake Panel** を選択して **インストール** → **起動**

## 開き方

| 経路 | URL | 認証 |
|---|---|---|
| サイドバー「地震速報」（Ingress） | Home Assistant 経由 | HA のログイン |
| キオスク端末から直接 | `http://<Home Assistant の IP>:8080/` | 無し（LAN 内限定） |

Raspberry Pi などを常時表示のキオスクにする場合は、後者の URL を
Chromium のキオスクモードで開きます。起動スクリプトの例は上流リポジトリの
`deploy/kiosk/` にあります。

認証なしのポートを開けたくない場合は、**設定 → ネットワーク** でポート 8080 を
空欄にしてください。Ingress からのみ開けるようになります。

### 音が鳴らないとき

ブラウザの自動再生制限のため、初回だけ画面のどこかをタップ／クリックする必要が
あります（「画面をタップして音声を有効化」が出ます）。キオスク端末では
Chromium に `--autoplay-policy=no-user-gesture-required` を付けると出なくなります。

音量や、予報から鳴らすか警報のみ鳴らすかは、**画面右上の「設定」**から
端末ごとに変えられます（アドオンの設定ではなく、その端末のブラウザに保存されます）。
設定画面の「音と明滅をテスト」で、実際の警報と同じ音と画面明滅を数秒出して
確認できます。

## 設定

### アドオンの設定タブ

サーバー全体に関わる（＝端末ごとには決められない）ものだけを置いています。

| 項目 | 既定 | 説明 |
|---|---|---|
| Home Assistant へ通知する | 有効 | 緊急地震速報などをイベントとセンサーに流す（[下記](#home-assistant-との連携)） |
| 地図に出す指標 | **最大加速度** | 強震モニタのどの指標を出すか。既定の最大加速度は揺れの検知が 1〜2 秒早い代わりに、交通や機械の振動を拾って平常時から全国がざわつきます（実測で緑以上の画素が約 100 倍）。静かな画面が好みなら**リアルタイム震度**へ。端末ごとにパネルの設定でも変えられます |
| 画像の取得間隔（平常時） | 1 秒 | 外部への通信量は平常時で約 8.5KB/s（1 日 700MB 程度）。2 秒にすると半分になる |
| 画像の取得間隔（EEW 中） | 1 秒 | 毎秒のままを推奨 |
| ログレベル | info | 動作を追いたいときだけ debug |

外部への通信量は画面を開いている端末の数に依存しません（このアドオンが
1 か所で取得し、各端末へ配ります）。

### パネルの「設定」（画面右上）

利用地や見た目は**その端末のブラウザ**に保存されます。アドオンの設定タブには
ありません。別の端末（キオスクの Pi と手元のスマホなど）で違う設定にできます。

**サーバーは常に全国の予報・警報を受信し、パネルと地図にも全国分を出します。**
ここで絞れるのは**音と明滅**（と履歴の表示）だけです。

| 章 | 項目 | 説明 |
|---|---|---|
| 利用地 | 緯度 / 経度 | 地図の初期位置と、地震速報・津波・履歴の「自分に関わるか」の判定に使う。決め方は[下表](#利用地の決め方) |
| リアルタイム表示 | 地図に出す指標 | サーバー既定に従うか、この端末だけ変えるか。いま出している指標は地図右下に常に表示されます |
| リアルタイム表示 | 表示位置を固定 | 地図の操作と境目のドラッグを受け付けなくする。常時表示の端末向け |
| 地震速報 | 音・明滅を出す速報 | 「利用地に関わるもののみ」か「全国すべて」。警報は、警報対象地域に利用地の県が入っているかで判定します |
| 地震速報 | 「関わる」とみなす震央距離 | 150km / 300km / **500km**（既定 300km）。対象地域の情報が無い第一報を震央からの距離で判定するためのもの。「全国すべて」のときは効きません |
| 地震速報 | 音・明滅を出す下限 | 「予報から出す」か「警報のみ」 |
| 津波予報 | 自分の予報区 | 既定は**利用地の都道府県から自動**。手動で都道府県を複数選ぶこともできる |
| 津波予報 | 音・明滅を出す下限 | 大津波警報のみ／津波警報以上／津波注意報以上／津波予報でも／出さない |
| 津波予報 | 利用地以外だけの大津波警報も知らせる | 自分の予報区が対象外でも、どこかに大津波警報が出ていれば鳴らす |
| 履歴パネル | 履歴に出す地震 | 最大震度のしきい値と「利用地の都道府県で揺れたものだけ」で絞る（表示だけ。音・明滅は出ません） |
| 履歴パネル | 履歴の表示件数 | 3〜12 件 |
| 音と明滅 | 音量 | — |
| 音と明滅 | 音を鳴らす時間 | 5 / 10 / 20 / 30 秒 / 鳴らし切る（既定 10 秒）。発表が続いていても、この時間で音だけ止めます |
| 音と明滅 | 画面明滅を続ける時間 | 15 / 30 / 60 秒 / 3 分 / 止めない（既定 60 秒）。パネル表示自体は消えません |
| 音と明滅 | 音と明滅をテスト | 実際の警報と同じ音と明滅を数秒だけ出す |
| 音と明滅 | デモ再生 | 予報 / 警報へ格上げ / キャンセル報 / 津波予報 の 4 つ。**接続中のすべての端末**で本物と同じ音と明滅が出ます（確認のワンクッションあり）。「停止」で進行中のデモを即座に消せます |

#### 利用地の決め方

| 方法 | 説明 |
|---|---|
| 緯度経度を直接入れる | — |
| 地図から選ぶ | 地図をクリックして決める。クリックは仮選択で、「決定」を押すまで保存されません |
| **現在地を取得** | その端末の位置情報を使います。ブラウザの仕様上、**HTTPS でアクセスしているときだけ**ボタンが出ます（Ingress 経由で HA 自体を HTTPS 化している場合を含む） |

取得した値を入力欄へ入れるだけで、**「保存」を押すまで確定しません**
（「取消」で開いた時点に戻せます）。

地図の拡大縮小・スクロールは**地図の上**で行います（右上の ＋ / − / 日本全体 /
利用地。ホイールとドラッグでも動きます）。動かした位置はその端末に保存され、
次に開いても同じ見え方になります。

地震情報の履歴は**押すと各地の震度が開きます**。

## Home Assistant との連携

やり取りは**パネル → HA の一方向だけ**です。パネルが HA を読みに行くことはありません。

「Home Assistant へ通知する」を無効にすると、この連携は止まります
（パネルの表示そのものは通常どおり動きます）。

### 通知

「Home Assistant へ通知する」を有効にすると（既定で有効）、緊急地震速報などを
HA のイベントとセンサーに流します。**画面を見ていなくても HA 側で気づける**
ようにするためで、オートメーションでダッシュボードを切り替える、照明を点ける、
といった使い方ができます。

**このアドオンでは震度や地域での絞り込みをしません。** 受け取ったものをそのまま
流すので、全国の小さな地震でもイベントは発火します。条件は
オートメーション側で書いてください（[例](#オートメーションの例)）。

流す処理はパネル本体ではなく、アドオンが持つ別プロセス（`ha-bridge.mjs`）が
やっています。受け口は 2 つです。

| 情報 | 受け取り方 |
|---|---|
| 緊急地震速報 | パネルの **webhook**（`EEW_WEBHOOK_URL`）を受ける。新規・続報・取消・表示終了が `kind` で分かります。同じ内容の続報は流しません |
| 地震情報・津波予報 | パネルの **WebSocket** につないで受ける（この 2 つには webhook が無いため） |

詳細は [HA-INTEGRATION.md](HA-INTEGRATION.md) を参照してください。

パネルの設定画面から出せる**デモ再生**の電文も、そのまま HA へ流れます。
本物と区別したいときは `is_demo` を条件に使ってください。

### イベント

続報のたびではなく、**意味が変わったときだけ**発火します（同じ地震で震度や
警報種別が変わらない続報では出ません）。

緊急地震速報の抑止は上流の webhook 側で行われていて、見ているのは
`id` / 報番号 / 取消 / 最終報 / 警報か予報か / 最大震度 / 震源（名前・緯度経度・
深さ・規模）と、**地域の「件数」だけ**です。件数が同じで地域ごとの予想震度や
到達予測時刻だけが変わった続報は飛びません（上流
[docs/eew-events.md](https://github.com/hgn32/quake-panel/blob/main/docs/eew-events.md)
§5）。最新の地域別の値が要る用途には向きません。

アドオンを再起動したときやパネルとの接続が切れて繋ぎ直したときは、
センサーの値だけ現況に合わせ直し、**イベントは発火しません**
（過去の発表でオートメーションが走らないようにするためです）。

| イベント | いつ | 主なデータ |
|---|---|---|
| `quake_panel_eew` | 緊急地震速報の受信・格上げ・取消・表示終了 | `kind` / `is_warning` / `max_intensity` / `hypocenter` / `report_number` / `is_cancel` / `is_training` / `is_assumption` / `regions` / `prefectures` / `hypocenter_lat` / `hypocenter_lon` / `is_demo` |
| `quake_panel_tsunami` | 津波予報の発表・解除 | `active` / `cancelled` / `areas` / `is_demo` |
| `quake_panel_quake` | 地震情報の受信 | `max_intensity` / `hypocenter` / `magnitude` / `occurred_at` |

### エンティティ

| エンティティ | 内容 |
|---|---|
| `binary_sensor.quake_panel_eew` | 緊急地震速報の発表中（訓練報・取消では `off`） |
| `sensor.quake_panel_eew_intensity` | 予想最大震度（`5強` など） |
| `binary_sensor.quake_panel_tsunami` | 津波予報の発表中 |
| `sensor.quake_panel_last_quake` | 最新の地震情報の最大震度 |

### オートメーションの例

緊急地震速報（警報）でダッシュボードを地震パネルに切り替える例です。
画面の切り替え自体は使っているカード／アドオン（browser_mod など）に合わせて
書き換えてください。

```yaml
alias: 緊急地震速報でダッシュボードを切り替える
triggers:
  - trigger: event
    event_type: quake_panel_eew
conditions:
  - condition: template
    value_template: "{{ trigger.event.data.is_warning and not trigger.event.data.is_training }}"
actions:
  - action: browser_mod.navigate
    data:
      path: /lovelace/quake
```

センサーで判定したい場合は `binary_sensor.quake_panel_eew` が `on` になったこと
をトリガーにできます。

震度で絞りたいときは、条件に `max_intensity` を足してください。値は `5弱`・`6強`
のような表示ラベルです。

```yaml
conditions:
  - condition: template
    value_template: >-
      {{ trigger.event.data.max_intensity in ['5弱', '5強', '6弱', '6強', '7'] }}
```

地域で絞りたいときは `prefectures`（予想震度が出ている地域の都道府県）を使います。
値は**電文のままで、緊急地震速報では `宮崎` のように県が付きません**
（地震情報の観測点は `宮崎県` と付く別の語彙なので、混同しないでください）。
細かく見たいときは `regions`（`宮崎県南部平野部` などの地域名）を使います。

**第一報では空になることがある**ので、空のときは落とさないようにしてください
（kmoni の予報は地域別の予想震度を持たないためです）。

```yaml
conditions:
  - condition: template
    value_template: >-
      {{ not trigger.event.data.prefectures
         or '宮崎' in trigger.event.data.prefectures }}
```

第一報を素通しにしたくない場合は、震源の緯度経度で代替できます。
`distance()` は HA の自宅（`zone.home`）からの距離（km）を返します。
パネル側も同じ考え方で、対象地域の情報が無い報は震央距離で判定していて、
選べる値は 150 / 300 / 500km（既定 300km）です。

```yaml
conditions:
  - condition: template
    value_template: >-
      {% set d = trigger.event.data %}
      {% set prefs = d.prefectures or [] %}
      {% set lat = d.hypocenter_lat %}
      {% set lon = d.hypocenter_lon %}
      {% set near = lat is none or lon is none
                    or (distance(lat, lon) or 0) <= 300 %}
      {{ '宮崎' in prefs if prefs else near }}
```

`kind` は `new`（新規発表）/ `update`（続報）/ `cancel`（取消）/ `expired`
（表示終了）です。**`expired` にも発表内容がそのまま入っている**ので、
発表を知らせる用途では `kind` で除いてください。

`expired` を取りこぼしたときは、最後に受け取ってから 5 分でアドオン側が畳み、
`kind: expired` を流します（ログタブに警告が出ます）。発表中のまま固まって、
次の地震で `binary_sensor.quake_panel_eew` が `off` → `on` に変化しなくなるのを
防ぐためです。

津波で絞りたいときは `areas`（津波予報区・全 98 区）を使います。**電文の予報区を
そのまま渡している**ので、1 区ごとに `name`・`grade`（`MajorWarning` /
`Warning` / `Watch` / `Unknown`）・`immediate`・第一波の到達予測・最大波高が
入っています。

予報区名は**都道府県名とは限りません**。3 つの型があるので、自分の県に関わる
区名を**すべて挙げて完全一致**で見てください。

| 型 | 例 |
|---|---|
| 県名そのもの | `宮崎県`、`岩手県` |
| 県名で始まる | `熊本県天草灘沿岸`、`千葉県九十九里・外房` |
| 複数県をまとめた領域表現 | `九州地方東部`（大分・宮崎ほか）、`有明・八代海`、`瀬戸内海沿岸` |

**部分一致は使わないでください**（`大阪府` の設定に `大分県瀬戸内海沿岸` が
当たります）。県ごとの区名は上流の
[`shared/src/tsunami.ts`](https://github.com/hgn32/quake-panel/blob/main/shared/src/tsunami.ts)
に一覧があります。緊急地震速報の `prefectures` は `宮崎` と県が付かない別の語彙
なので、混同しないでください。

解除（取消）では `active` が `false`、`cancelled` が `true` になり、`areas` は
空になります。発表だけを知らせたいときは `active` で絞ってください。

```yaml
triggers:
  - trigger: event
    event_type: quake_panel_tsunami
    event_data:
      active: true
conditions:
  - condition: template
    value_template: >-
      {{ trigger.event.data.areas
         | selectattr('name', 'in', ['宮崎県', '九州地方東部'])
         | list | count > 0 }}
```

## 外部への接続先

稼働中に通信する先は次の 2 つだけです。送信許可リストを組む場合はこれが対象です。

| 宛先 | 用途 |
|---|---|
| `www.kmoni.bosai.go.jp` (HTTP) | 強震モニタの震度画像・緊急地震速報 JSON |
| `api.p2pquake.net` (HTTPS/WSS) | 地震情報・津波予報・緊急地震速報 |

P2P地震情報の WebSocket は IP あたり 2 本までという制限があります。
このアドオンは 1 本だけ張り、各端末へは自前で配るので制限には触れません。

## 状態の確認

- **ログタブ**: 起動時の設定内容と、上流の疎通状況が出ます
- **画面上部**: 「サーバー」「強震モニタ」「地震情報」の状態が常に表示されます
  （それぞれにマウスを重ねると、何のデータかの説明が出ます）。強震モニタに
  つながらなくなった場合は、地震情報のみの**劣化モード**で表示を継続します
  （画面にその旨が出ます）

保存するデータはありません（すべてメモリ上に持ちます）。そのため、アドオンを
再起動すると履歴は P2P地震情報から取り直されます。

## 上流の固定について

アプリ本体は [hgn32/quake-panel](https://github.com/hgn32/quake-panel) にあり、
`upstream.env` でコミットを固定してビルドしています。上流が private へ戻っても
取得できるよう、Dockerfile では clone せず、GitHub Actions がトークン付きで
取得してビルドコンテキストへ置き、Dockerfile はそれを取り込みます。

上流を取り込むときは `upstream.env` の `UPSTREAM_REF` を新しいコミットにして、
`config.json` の `version` も必ず上げてください。

電文の中身や webhook の発火条件を確かめたいときは、上流のドキュメントが一次資料です。

| 上流の文書 | 中身 |
|---|---|
| `docs/eew-events.md` | EEW webhook が**いつ**飛ぶか（`kind` の決まり方・続報の抑止・`expired` の期限・デモの挙動） |
| `docs/area-codes.md` | 電文に入る地名の値域（都道府県 47 / 細分区域 188 / 府県予報区 56 / 津波予報区 98） |
| `docs/kmoni-endpoints.md` | 強震モニタと P2P地震情報の API リファレンス |

private リポジトリを取得するため、このリポジトリの
**Actions シークレット `UPSTREAM_REPO_TOKEN`** に、上流の読み取り権限がある
トークン（fine-grained PAT: Contents = Read-only）を登録しておく必要があります。
上流が public なら不要です。

手元でビルドするときは自分でソースを置いてください:

```bash
set -a; . quake-panel/upstream.env; set +a
git clone https://github.com/${UPSTREAM_REPO}.git quake-panel/upstream
git -C quake-panel/upstream checkout --detach "${UPSTREAM_REF}"
docker build -t quake-panel quake-panel/
```
