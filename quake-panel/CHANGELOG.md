  - 「奄美」を対象にした緊急地震速報（警報）で、鹿児島県の端末が警報にならなかった
    のが直りました（電文は `奄美(群島)` ではなく `奄美` で来ます）
  - 予想震度の上限が「〜程度以上」（P2P の `99`）のとき、上限なしとして扱うように
    なりました
  - 上流に API リファレンス（`docs/kmoni-endpoints.md`）・地名の値域
    （`docs/area-codes.md`）・EEW webhook の発火条件（`docs/eew-events.md`）が
    追加されました
- **緊急地震速報のイベントに `is_assumption`（仮定震源要素）を追加しました。**
  精度の低い報を除きたいときに使えます
- **README を現状に合わせて直しました。**
  - **URL のクエリパラメータで設定を上書きする機能は上流で廃止されています**
    （0.3.0 で取り込んだ時点で無くなっていました）。説明を削除しました
  - パネルの設定画面の説明を現行の項目に更新（「関わる」とみなす震央距離、
    デモ再生と停止、利用地以外だけの大津波警報も知らせる、など）
  - 津波の絞り込み例を直しました。**津波予報区は都道府県名とは限らず**、
    宮崎県の沿岸は領域表現「九州地方東部」で来ることがあります。
    例を `['宮崎県', '九州地方東部']` の完全一致に修正しました
  - 緊急地震速報の続報は**地域の「件数」しか見ていない**ため、件数が同じで
    地域別の予想震度だけが変わった続報は流れないことを明記しました

## 0.3.2

- **津波予報のイベントとエンティティで、予報区を電文のまま渡すようにしました。**
  `areas` が予報区名の配列から**予報区そのものの配列**に変わり、1 区ごとに
  `name` / `grade`（`MajorWarning` / `Warning` / `Watch` / `Unknown`）/
  第一波の到達予測 / 最大波高 が入ります。「宮崎県は注意報なのか大津波警報なのか」を
  オートメーションで判定できるようになります
  - **`grades` は無くなりました。** 全国の階級を重複除去しただけの値で、
    どの予報区がその階級なのかが分からなかったためです
  - `areas` を名前で見ている場合は書き換えが必要です。
    例: `'宮崎県' in trigger.event.data.areas` →
    `trigger.event.data.areas | selectattr('name', 'eq', '宮崎県') | list | count > 0`
  - 予報区名は `宮崎県` と**県が付きます**（緊急地震速報の `prefectures` は
    `宮崎` と付かない別の語彙です）

## 0.3.1

- **緊急地震速報のイベントに震源の緯度経度（`hypocenter_lat` / `hypocenter_lon`）を
  追加しました。** 地域別の予想震度がまだ無い第一報でも、HA 側で
  `distance()` を使って「自宅からどれくらいか」で絞れます
- **緊急地震速報のイベントに `regions` と `prefectures` を追加しました。**
  予想震度が出ている地域名（`宮崎県南部平野部` など）と、その都道府県です。
  オートメーションで「自分の県に関わるものだけ」と絞れるようになります
  - `prefectures` は**電文の値そのまま**で、緊急地震速報では `宮崎` のように
    **県が付きません**（地震情報の観測点は `宮崎県` と付く別の語彙です）
  - kmoni の第一報は地域別の予想震度を持たないため、**空になることがあります**
    （空を「該当なし」と扱うと第一報を落とすので注意してください）
- **上流を最新（`c378275`）に更新しました。**
  - 緊急地震速報の続報が同じ内容のときは webhook を送らないようになりました
    （発表中ずっと秒間隔で送られていたのが止まります）
  - デモ再生に停止ボタンが付きました
  - 画像と音の後始末、不正な URL でのクラッシュ、起動直後に停止したときに
    終了処理が走らない問題などが直りました
