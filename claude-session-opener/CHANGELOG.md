## 0.6.1

- **貼り付けたコードを送信しても無反応になるのを修正。** コード本体と確定の
  改行(CR)を1回の書き込みでまとめて送っていたため、CLI の入力欄がそれを
  「貼り付け」として扱い、改行を確定操作にしていなかった。実測では61文字なら
  通るが80文字以上で無反応になる。実際の認証コードは92文字前後なので必ず踏む。
  コードと改行を分けて送るようにした
- **発行を中止した直後に再発行すると、画面が勝手に元に戻る**のを修正。
  止めた側のプロセスの終了処理が、新しく始めたフローの状態を消していた
- パネルに **CLI の画面**を出すようにした。うまくいかないときに、CLI が実際に
  何を表示しているかをそのまま確認できる（トークンは伏せる）。
  エラー時は自動で開く。ログにも同じ内容を出す
- エラー表示に CLI の原文を併記するようにした
- パネルに **「接続を確認」** を追加。`platform.claude.com` と
  `api.anthropic.com` に到達できるかをその場で確認できる。
  コード送信後に応答が無かったときは自動で確認して結果を出す

## 0.6.0

- **実行が失敗したのに通知が出なかったのを修正。** 長期トークンが読めない状態だと、
  毎朝の実行が失敗しても通知せずに黙って終わっていた。トークンの有無に関わらず
  失敗したら必ず通知する。トークン未設定で実行できなかったときも通知する
- 失敗の理由をそのまま出すようにした。これまでは「終了コード: 1」と生の JSON が
  300文字で切れていて、肝心の理由（例: `401 OAuth access token is invalid`）が
  見えなかった。通知・ログ・パネルのどれでも読める
- 実行失敗の通知は**実行が成功するまで消さない**ようにした（トークンを削除・再発行
  しただけでは消えない）
- **認証パネルを MUI で作り直した。** 処理中はボタンと入力欄が無効になり、
  認証コードは貼り付けだけで送れる
- **コードの送信が無反応になるのを修正。** CLI のエラー画面は
  `OAuth error: ...` で、`Invalid code` という文言はもう出ない。これを拾えず
  「確認中…」のまま固まっていた。エラーの理由を日本語で表示し、
  自動でやり直して入力待ちに戻す。あわせて、やり直すと認証 URL が新しくなる
  （前の URL のコードは通らない）ことを画面で案内する
- パネルに「最後の実行結果」「今すぐ実行して確認」「テスト通知を送る」を追加。
  トークンを保存した直後は自動で1回だけ実行して、使えるトークンか確かめる
- 実行が返ってこないときは3分で打ち切って失敗として通知するようにした
- 長期トークンの取り出しで、末尾のパディング（`=`）を落として保存してしまう
  可能性があったのを修正。途中まで保存されると毎朝 401 で失敗し続ける

## 0.5.0

- 認証を `claude setup-token` が発行する**1年有効**の長期トークンだけにした。
  「Claude 認証」パネルから発行できる。ログイン（`claude auth login`）は廃止
- 毎朝の実行が失敗したとき・トークンの期限が切れた/近いときに、
  Home Assistant の**通知パネルへ通知**するようにした。
  復帰したら自動で消える。イベントやエンティティは作らない
- 設定に「Home Assistant へ通知する」を追加（既定で有効）
