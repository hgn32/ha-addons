# Claude Session Opener

Claude Pro/Max サブスクリプションの「5時間セッション制限」を、毎朝決まった時刻を
起点にリセットさせるため、最小トークンのタスクを自動送信する Home Assistant
アドオンです。`claude setup-token` が発行する1年有効の長期トークン（サブスクリプション
認証）を使い、API キーは使いません。
実際にセッションがリセットされているかは `claude` の `/usage` で確認できます。

## 対応アーキテクチャ

| アーキテクチャ | 対応状況 |
|---|---|
| amd64 | ✅ |
| aarch64 | ✅ |

## インストール

1. Home Assistant の **設定 → アドオン → アドオンストア** を開く
2. 右上のメニューから **リポジトリを追加** を選択し、以下の URL を入力する
   ```
   https://github.com/hgn32/ha-addons
   ```
3. **Claude Session Opener** を選択して **インストール**

## 設定（複数アカウント対応）

アドオンの **設定** タブで `accounts` に、アカウントごとの名前と実行時刻を
追加します。

```yaml
accounts:
  - name: "仕事用"
    schedule_time: "07:00"
  - name: "個人用"
    schedule_time: "22:00"
```

`schedule_time` は `HH:MM`（**UTC**）です。日本時間の朝7時にしたい場合は
`22:00`（前日の UTC 22:00 = JST 07:00）にしてください。

| 設定 | 既定 | 説明 |
|---|---|---|
| アカウント | `default` / `07:00` | 名前と毎日の実行時刻（UTC）。何件でも追加できます |
| Home Assistant へ通知する | 有効 | 毎朝の実行が失敗したときなどに HA の通知パネルへ通知します（[下記](#通知)） |

## 初回セットアップ（長期トークンの発行）

アカウントごとに、初回だけ Claude Pro/Max サブスクリプションアカウントでの
認証が必要です。`claude setup-token` が発行する**1年有効**の長期トークンを使います
（`claude` のログイン認証情報は有効期限が短く、毎朝の実行しかしないこのアドオンでは
すぐ切れてしまうため、こちらだけを使います）。

1. アドオンを起動する
2. サイドバーの **「Claude 認証」** パネルを開く（設定した accounts が
   それぞれカードで表示されます）
3. 対象アカウントのカードで **「長期トークンを発行」** を押す
4. 表示された URL をブラウザで開いて認証し、表示されたコードをカードに
   貼り付けて **「送信」**
5. カードに「長期トークンで認証しています（残り約 N 日）」と出れば完了

トークンはアカウントごとに `/data/claude-credentials/<アカウント名>/` に
保存されます（パーミッション 600）。コンテナを再起動しても維持され、
このアドオンを選んでバックアップを取れば含まれます。

> パソコンで `claude setup-token` を実行して得たトークンを、カードの
> 「手元で発行したトークンを貼り付ける」から登録することもできます。
> パネル内での発行がうまくいかないときの逃げ道です。

## 通知

**アドオンから Home Assistant へ出すのは通知パネルへの通知だけ**です
（設定タブの **「Home Assistant へ通知する」** が有効なとき。既定で有効）。
オートメーションやイベント、エンティティは作りません。

| きっかけ | 通知の内容 |
|---|---|
| 毎朝の実行が認証エラーで失敗した | 「セッションが切れました」 |
| 毎朝の実行がそれ以外の理由で失敗した | 「実行に失敗しました」＋理由 |
| 長期トークンの期限が切れた / 残り14日を切った | 再発行の案内 |

- 通知はアカウントごとに**同じ通知に上書き**されるので、積み上がりません。
  次の日の実行が成功すれば**自動で消えます**
- 判定は**毎朝の実行結果**と、アドオン起動時のトークンの日付だけで行います。
  状態確認のためにコマンドを定期実行することはありません

## ログの確認

毎日の実行結果と認証チェックの結果は HA の
**設定 → アドオン → Claude Session Opener → ログ** タブで確認できます。
どのアカウントの実行かは行頭の `[アカウント名]` で判別できます。ログはファイルに保存せず、この画面にのみ出力されます。
API キーや認証トークンは一切出力しません。
