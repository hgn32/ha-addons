# Claude Session Opener

Claude Pro/Max サブスクリプションの「5時間セッション制限」を、毎朝決まった時刻を
起点にリセットさせるため、最小トークンのタスクを自動送信する Home Assistant
アドオンです。サブスクリプション（OAuth）ログインを使い、API キーは使いません。
実際にセッションがリセットされているかは `claude` の `/usage` で確認できます。

## 対応アーキテクチャ

| アーキテクチャ | 対応状況 |
|---|---|
| amd64 | ✅ |
| aarch64 | ✅ |

## インストール

1. Home Assistant の **設定 → アドオン → アドオンストア** を開く
2. 右上のメニューから **リポジトリを追加** を選択し、以下の URL を入力する
   ```
   https://github.com/hgn32/ha-addons
   ```
3. **Claude Session Opener** を選択して **インストール**

## 設定（複数アカウント対応）

アドオンの **設定** タブで `accounts` に、アカウントごとの名前と実行時刻を
追加します。

```yaml
accounts:
  - name: "仕事用"
    schedule_time: "07:00"
  - name: "個人用"
    schedule_time: "22:00"
```

`schedule_time` は `HH:MM`（**UTC**）です。日本時間の朝7時にしたい場合は
`22:00`（前日の UTC 22:00 = JST 07:00）にしてください。

| 設定 | 既定 | 説明 |
|---|---|---|
| アカウント | `default` / `07:00` | 名前と毎日の実行時刻（UTC）。何件でも追加できます |
| Home Assistant へ通知する | 有効 | 認証が切れたときなどに HA へ通知します（[下記](#セッション切れの通知)） |

## 初回セットアップ（認証）

アカウントごとに、初回のみ Claude Pro/Max サブスクリプションアカウントでの
認証が必要です。方法は 2 つあり、**長期トークンをおすすめします**。

| 方法 | 有効期間 | 向き |
|---|---|---|
| **長期トークン**（推奨） | **約1年** | 毎朝の自動実行だけをさせるこのアドオン向け |
| ログイン | 短い（切れたら都度やり直し） | すぐ試したいとき |

どちらもサイドバーの **「Claude Login」** パネルから、HA の画面だけで完結します。

### 長期トークンを発行する（推奨）

1. アドオンを起動する
2. サイドバーの **「Claude Login」** パネルを開く（設定した accounts が
   それぞれカードで表示されます）
3. 対象アカウントのカードで **「長期トークンを発行（1年有効・推奨）」** を押す
4. 表示された URL をブラウザで開いて認証し、表示されたコードをカードに
   貼り付けて **「送信」**
5. カードに「長期トークンで認証しています（残り約 N 日）」と出れば完了

これは Claude Code の `claude setup-token` が発行する 1 年有効の OAuth トークン
（`CLAUDE_CODE_OAUTH_TOKEN`）で、毎朝の実行時にこのトークンを使います。
期限が残り 14 日を切ると HA に通知が出るので、そのときに
**「長期トークンを再発行」** を押してください。

> パソコンで `claude setup-token` を実行して得たトークンを、カードの
> 「手元で発行したトークンを貼り付ける」から登録することもできます。
> パネル内での発行がうまくいかないときの逃げ道です。

### ログインで認証する

1. カードの **「ログインを開始」** を押す
2. 表示された URL をブラウザで開いてログイン
3. 表示された認証コードをカードに貼り付けて **「送信」**

こちらは有効期限が短く、切れるたびにやり直しになります。切れたときは
下記のとおり HA に通知が出ます。

認証情報はアカウントごとに `/data/claude-credentials/<アカウント名>/` に
保存されます。コンテナを再起動しても維持され、このアドオンを選んで
バックアップを取れば含まれます。

## セッション切れの通知

認証状態を 30 分ごとに確認し、次のときに Home Assistant へ通知します
（設定タブの **「Home Assistant へ通知する」** が有効なとき。既定で有効）。

| きっかけ | 通知の内容 |
|---|---|
| 認証が切れた | 「セッションが切れました」＋理由 |
| 毎朝の実行が失敗した | 失敗した理由 |
| 長期トークンの残りが 14 日を切った | 再発行の案内 |

通知は HA の**通知パネル**に出ます。同じアカウント・同じ種類の通知は 1 件に
まとまり、**復帰すると自動で消えます**。

あわせて、オートメーションから使えるイベントも送ります。スマホへプッシュしたい
場合などに利用してください。

| イベント | 発生するとき | データ |
|---|---|---|
| `claude_session_opener_auth_lost` | 認証が切れた | `account` / `slug` / `reason` |
| `claude_session_opener_auth_restored` | 認証が回復した | `account` / `slug` |
| `claude_session_opener_run_failed` | 毎朝の実行が失敗した | `account` / `slug` / `detail` |
| `claude_session_opener_token_expiring` | トークンの期限が近い | `account` / `slug` / `days_left` |

スマホに飛ばす例（オートメーションの YAML）:

```yaml
triggers:
  - trigger: event
    event_type: claude_session_opener_auth_lost
actions:
  - action: notify.mobile_app_<あなたの端末>
    data:
      title: Claude のセッションが切れました
      message: "{{ trigger.event.data.account }}: {{ trigger.event.data.reason }}"
```

## ログの確認

毎日の実行結果と認証チェックの結果は HA の
**設定 → アドオン → Claude Session Opener → ログ** タブで確認できます。
どのアカウントの実行かは行頭の `[アカウント名]` で判別できます。ログはファイルに保存せず、この画面にのみ出力されます。
API キーや認証トークンは一切出力しません。
