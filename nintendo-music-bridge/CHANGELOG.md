## 0.4.1

- 許可していない接続元からのアクセスを拒否したとき、その接続元をログタブに出すようにした
- Chrome が異常終了したとき、Chrome の最後の出力をログタブに出すようにした

## 0.4.0

- パネルに再生画面を追加。検索 → ゲーム → プレイリスト → 曲を選んで再生でき、一時停止・再開・
  前・次の操作と再生中の曲の表示もできる
- 設定の「言語」（`lang`）を Chrome の画面と Nintendo Music のページにも反映するようにした（既定は日本語）
- Chrome の `--no-sandbox` の警告バーと、落ちたあとの「ページを復元しますか？」を出さないようにした
- HA の内部ネットワーク（172.30.32.0/23）からブリッジ API を使えるようにした（ha-mcp などのアドオンから）。
  LAN からは引き続き使えない

## 0.3.0

- ブリッジ API を追加。検索・ゲーム一覧・プレイリストの中身の取得と、プレイリストの再生・一時停止・
  再開・次・前の操作を HTTP で行える（HA の `rest_command` などから使える）
- 設定に `lang`（既定 `ja-JP`）と `country`（既定 `JP`）を追加
