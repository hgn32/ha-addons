## 0.3.0

- ブリッジ API を追加。検索・ゲーム一覧・プレイリストの中身の取得と、プレイリストの再生・一時停止・
  再開・次・前の操作を HTTP で行える（HA の `rest_command` などから使える）
- 設定に `lang`（既定 `ja-JP`）と `country`（既定 `JP`）を追加

## 0.2.0

- 調査モードを追加（ブリッジ API を作るための下調べ）。Web 版自身が呼ぶ API と画面の部品を記録して
  コピーできる。認証トークン・ライセンス関係の通信・リクエストヘッダは記録しない
- 起動直後に音声の出力先の切り替えが `Not supported` で断られ、アドオンが落ちることがあったのを修正
  （通るまで待つようにした）
- Chrome を CDP（127.0.0.1:9222）付きで起動するようにした

## 0.1.0

- 初版（フェーズ0: 実現可否の確認用）。公式 Chrome を Xvfb 上で常駐させて画面を Ingress に出し、
  Chrome の音声を VBAN で Music Assistant の VBAN Receiver へ送る
