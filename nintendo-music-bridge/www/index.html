お気に入り
HA のオートメーションから再生するには アクション「イベントを発行」（event）で次を発行します。favorites はお気に入りの名前（複数なら順に再生）、entity_id はスピーカーです。 
event: web_music_player_play
event_data:
  favorites: ["朝のBGM", "ピクミン"]
  entity_id: media_player.jbl_bar_800
favorites を省くとお気に入りの全部を、shuffle: true を付けると順番を混ぜて再生します。 止めるときは event: web_music_player_stop を発行します。
調査モード（ブリッジ API を作るための下調べ）
  1. 「調査を開始」を押す
  2. 画面内で、検索 → 検索結果からゲームやプレイリストを開く → 曲を再生、と普段どおり操作する。要所で「画面の部品を記録」を押す（検索結果・プレイリスト・再生中の各画面で1回ずつ）
  3. 「調査を終了」→「結果をコピー」で、Claude に貼り付ける

認証トークン・ライセンス関係の通信・リクエストヘッダは記録しません。
